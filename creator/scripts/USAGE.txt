To use the script and update the dataset cache

php PATH/ckan_dataset_generator.php > CREATOR_PATH/datasets.js

To change or add a provider, edit the $providers variable in the PHP script.

 $providers =  array(
                  new Provider(
                     "p1",
                     "REGIONE CAMPANIA",
                     "https://dati.regione.campania.it/ckan"
                  )
                  ...
                  new Provider(
                      "MY_ID",
                      "MY_PROVIDER_NAME",
                      "MY_PROVIDER_URL"
                  )

            );
